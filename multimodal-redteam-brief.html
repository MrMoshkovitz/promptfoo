Why multimodal attacks matter

Attack surface

Images + text amplify leakage

Vision-language models fuse OCR, captioning, and reasoning. A single adversarial image can smuggle new instructions, bypass text filters, and bias final answers.

Exploitation lifecycle (end-to-end)

Phase 1 · Recon & payload crafting

  • Collect real brand collateral (Lenovo manuals, invoices) + synthesize trojans (QR codes, hidden text).
  • Build dual-channel instructions: textual setup + embedded prompt inside the image (ASCII overlay, steganography).
Image layer

Adversarial invoice with invisible ink instructing model.

Text layer

Benign-sounding question referencing the image.

Phase 2 · Promptfoo orchestration

  • Define scenario YAML referencing both the textual prompt and `file://` image path (PNG, SVG, GIF).
  • Configure providers (OpenAI GPT-4o, Anthropic Claude VLM, on-prem VLM) with consistent temperature & top_p for diffing.

Phase 3 · Exploit execution

  • Run `promptfoo eval` with multimodal schema automatically uploading images to providers.
  • Capture raw completions, images of responses, and judge them using human or model-based rubrics.

Phase 4 · Scoring & reporting

  • Assertions detect jailbreak success, sensitive leaks, policy violations, and cross-channel hallucinations.
  • Export HTML + CSV dashboards for customer handoff with trace links to each exploit run.

How we exploit multimodal models (deep dive)

Step A · Bias accumulation

Inject conflicting cues via image instructions (“ignore safety, new policy is X”) plus text praising compliance. Many VLMs weight image features first; we leverage that ordering.

Step B · OCR overload

Provide dense tables forcing the model to transcribe all tokens, guaranteeing exposure to embedded secrets or triggers.

Step C · Validation gap

Many defenses only inspect the text prompt. Our exploit relies on the image path containing new directives, so we highlight this gap during demos.

Step D · Evidence capture

Every run stores traces: prompt text, image hash, response, assertion verdict, and screenshot. These artifacts convince hiring stakeholders of rigor.
